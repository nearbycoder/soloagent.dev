    Durable by default

    Crash it. Redeploy it.
    It picks up where it stopped.

    Agents run on Pi Durable. Every model turn and every tool call is committed to SQLite before you see it. When the process dies, the run resumes from the last committed step instead of starting over or silently vanishing.

    • Commit before show. What you see in chat is always something that's already on disk.
    • Resume, don't restart. Completed steps aren't run again after a crash, restart, or deploy.
    • Sleep for days. Scheduled reminders wait in storage and still fire after restarts.
    • Durable delegation. When one agent asks another, the child conversation is durable too.

    Open source & self-hosted

    Your keys. Your data.
    Your server.

    soloagent is MIT licensed and runs as a single service. Everything lives in one data directory you own.

    • One service on Railway with a volume at /data. Or Docker, or any machine with Node 22+.
    • Credentials sealed with AES-256-GCM using your SOLOAGENT_SECRET.
    • A typed SDK. @soloagent/client speaks the same REST + WebSocket API as the GUI and TUI.
    • Or embed the core directly as a library with SoloAgent.open().
    Deploy on Railway Read the API docs
    example.ts
    import { SoloClient } from "@soloagent/client";

const solo = new SoloClient({
  baseUrl: "https://solo.example.com",
  token: process.env.SOLOAGENT_TOKEN,
});

const thread = await solo.createThread({ agentId: "coder" });
const { answer } = await solo.ask(thread.id, "Summarize today's deploys");

// Or stream every token as it lands
const live = solo.connect();
live.subscribe(thread.id);
live.on((event) => { if (event.type === "thread.live") render(event.live); });

    FAQ

    Questions, answered.

    Something else? Open an issue on GitHub.

    What does it cost?

    soloagent is free and MIT licensed. You pay for your own hosting (one small service) and whatever model subscriptions or API usage you connect. The dashboard tracks usage and cost per model and per agent.

    Can I really use my Claude or ChatGPT subscription?

    Yes. Claude Pro/Max, ChatGPT, GitHub Copilot, SuperGrok/X Premium, OpenRouter, and others can sign in through OAuth from the dashboard or the terminal. If you prefer, use an API key instead. Review your provider's terms for how your plan may be used.

    What happens if the server restarts mid-answer?

    Nothing is lost. Each model turn and tool call is committed to SQLite before it's shown, so on restart the run resumes from the last committed step. Scheduled reminders keep sleeping in storage and fire on time.

    Do I need a public URL for Slack?

    No. The Slack connector uses Socket Mode, so the server opens the connection outward. You only need a public URL for inbound webhooks and to reach the dashboard from elsewhere.

    Where is my data stored?

    In a single data directory on your server: a SQLite database holding threads, agent memory, schedules, and credentials. Credentials are sealed with AES-256-GCM using SOLOAGENT_SECRET.

    What is Pi?

    Pi is Earendil's agent toolkit. soloagent uses @earendil-works/pi-ai to talk to model providers and @earendil-works/pi-durable for durable execution.

    Can I build on top of it?

    Yes. Use the HTTP and WebSocket API, the typed @soloagent/client SDK, or embed the core with SoloAgent.open({ dataDir }).
