§01On the record

Crash it mid-answer. It picks up where it stopped.

soloagent is built on Pi Durable. Every model turn, tool call, delegation, and reminder is a durable step in SQLite. A deploy, a crash, or a container restart is a pause, not a reset.

Commit before show
Nothing reaches Slack or the dashboard until it has been written to storage.
Resume, don't restart
An interrupted model request is retried. Finished tool calls never run twice.
Timers that outlive the process
A reminder set for Friday sleeps in storage and fires on Friday, across any number of deploys.

§02Models

Use the subscriptions you already pay for.

Model access runs through @earendil-works/pi-ai. Sign in with a consumer plan or paste an API key, then give each agent its own model and thinking level: coding on Claude, research on ChatGPT, triage on something cheap.

Sign in with a subscription

  • Claude Pro & Maxoauth
  • ChatGPT Plus & Prooauth
  • GitHub Copilotoauth

Or bring an API key

Anthropic, OpenAI, Google Gemini, Mistral, Groq, DeepSeek, xAI, Amazon Bedrock, Azure OpenAI, Vercel AI Gateway, Together, Fireworks, Cerebras, Hugging Face, any OpenAI-compatible endpoint, and more.

Sealed at rest. Keys and tokens are encrypted with AES-256-GCM under a secret you control, refresh automatically, and never reach the browser. A built-in demo model works before you connect anything.

§03Channels

One set of agents, every place your team talks.

Connect a platform once and every agent is reachable there. In chat apps, replies stream in live by editing a placeholder message while the agent works.

#ChannelConnects withWhat it does
C1SlackSocket Mode. No public URL needed.Answers mentions in a thread, and direct messages.
C2DiscordBot token, Message Content intent.Mentions, replies, and DMs. Each Discord thread is its own conversation.
C3TelegramBot token from @BotFather.Direct messages, group mentions, and forum topics.
C4WebhooksShared secret on POST /api/hooks/:id.Answers in the response, or posts to a callback_url.
C5WebBuilt in, same process.Chat, agents, sign-ins, connections, task graph, and usage.
C6TerminalEmbedded, or soloagent connect.Full-screen TUI, plus soloagent ask for scripts and pipes.

Routing that reads like chat.

Start with @coder or coder: to address an agent; otherwise the channel's assigned agent answers. Send another message while it works and you steer the run in progress instead of queuing behind it.

§04Interfaces

A dashboard for the team. A terminal for you.

Both talk to the same server over the same API. The terminal UI runs its own private server when you're not connected to one.

§05Skills

Agents with skills, not just prompts.

Give each agent a name, a handle, instructions, a model, and only the skills it needs. Skills are Pi Durable extensions, so their work is on the record too.

  • memoryremember · recall · forget

    Keeps people, preferences, and decisions across every conversation.

  • webweb_fetch · web_search

    Reads pages and APIs as clean text, and searches the web.

  • delegateask_agent

    Hands a task to another agent through a durable child conversation.

  • scheduleschedule_reminder

    Reminders and follow-ups that sleep in storage and fire after restarts.

  • workspaceread · write · edit · bash

    Files and shell in a private folder. Powerful, so it's off by default.

§06Developers

Scriptable from end to end.

Everything the dashboard and terminal do goes through a documented HTTP and WebSocket API. Use the typed TypeScript client, call it from CI, or embed the runtime in your own service.

  • REST for agents, threads, providers, connectors, schedules
  • WebSocket stream of messages, partial answers, and tool progress
  • One bearer token per deployment

Read the API reference

# ask once, print the answer
soloagent ask "Summarize today's incidents" --agent ops

# pipe anything in
git diff --staged | soloagent ask - --agent coder

# use a remote server from now on
soloagent connect https://solo.example.com \
    --token $SOLOAGENT_TOKEN
import { SoloClient } from "@soloagent/client";

const solo = new SoloClient({
  baseUrl: "https://solo.example.com",
  token: process.env.SOLOAGENT_TOKEN,
});

const thread = await solo.createThread({ agentId: "coder" });
const { answer } = await solo.ask(thread.id, "Why did CI fail?");

// stream partial answers and tool progress
solo.connect().subscribe(thread.id);
# from anything that can send a request
curl -X POST $SOLO/api/hooks/$HOOK_ID \
  -H "x-solo-secret: $HOOK_SECRET" \
  -H "content-type: application/json" \
  -d '{"text": "@coder what changed in the last deploy?",
       "thread": "deploys", "user": "ci"}'

# → {"thread":"deploys","status":"done","answer":"…"}
§07Self-host

Your keys, your data, your server.

soloagent is a single Node.js service with a single data directory. Deploy it to Railway in a few minutes, or run it anywhere with Docker or Node 22.19+.

  1. 01

    Deploy

    Create a Railway service from the repo and attach a volume at /data. The Dockerfile does the rest.

  2. 02

    Configure

    Set SOLOAGENT_TOKEN for access and SOLOAGENT_SECRET to seal credentials.

  3. 03

    Connect

    Sign in to a model provider, create agents, then add Slack, Discord, or Telegram.

Or run it on your machine.

The terminal UI starts an embedded server with its data in ~/.soloagent. soloagent serve adds the web dashboard on port 7420.

shell
git clone https://github.com/nearbycoder/soloagent.dev
cd soloagent.dev
npm install && npm link -w @soloagent/cli
soloagent
§08Questions
Is it free?
Yes. soloagent is MIT-licensed and self-hosted. You pay your model provider and your host, nothing else.
Can I really use my Claude or ChatGPT subscription?
Yes, through the same OAuth sign-in flows Pi uses. Check each provider's terms; Anthropic, for example, bills third-party usage as extra usage rather than against plan limits.
What happens if the server restarts mid-answer?
The run resumes from its last committed step. Completed tool calls are not repeated, and an interrupted model request is retried.
Do I need a public URL for Slack?
No. Slack uses Socket Mode, and Discord and Telegram connect outbound too. A domain is only needed for the dashboard, webhooks, and remote terminal access.
Where is my data stored?
In two SQLite databases in your data directory. Nothing leaves your server except requests to the model providers you configure.
What is Pi?
Earendil's open-source agent toolkit. soloagent uses pi-ai for models, pi-durable for durable execution, and pi-tui for the terminal UI.
