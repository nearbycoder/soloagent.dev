Durable by default

Crash it mid-answer. It picks up where it stopped.

soloagent is built on Pi Durable. Every model turn, tool call, delegation, and reminder is a durable step in SQLite. A deploy, a crash, or a container restart is a pause, not a reset.

  • Commit before show

    Every model turn and tool call is written to storage before Slack or the dashboard shows it. Streaming text is saved as it arrives.

  • Resume, don't restart

    An interrupted model request is retried. Finished tool calls never run twice.

  • Timers that outlive the process

    A reminder set for Friday sleeps in storage and fires on Friday, across any number of deploys.

  • Waits that survive restarts

    A tool call waiting for approval stays waiting through a restart, and an approved call runs once.

Channels

One set of agents. Every place your team talks.

Connect a platform once and every agent is reachable there. In chat apps, replies stream in live by editing a placeholder message while the agent works.

  • Slack

    Socket Mode · no public URL

    @mention an agent in a channel and the reply streams into the thread. DMs too.

  • Discord

    Bot token · Message Content intent

    Mentions, replies, and DMs. Each Discord thread is its own conversation.

  • Telegram

    Bot token from @BotFather

    Direct messages, group mentions, and forum topics.

  • Webhooks

    POST /api/hooks/:id

    Answers in the response, or posts to a callback_url when it's done.

  • Web dashboard

    Built in · same process

    Chat with streaming, agents, sign-ins, connections, approvals, and usage.

  • Terminal

    soloagent · soloagent ask

    A full-screen TUI, plus one-shot answers for scripts and pipes.

Teams

Ready for the whole team.

Invite people, decide who reaches which agents from where, and put a ceiling on spend.

  • Access lists

    Limit each connection to certain people, channels, and agents. Anyone else gets one short reply, and the attempt is logged.

  • Budgets and rate limits

    A daily spend or message limit per agent, and messages per person per hour. Over a limit, chat gets a friendly reply and the API returns 429.

  • Users and roles

    Invite people with a one-time link. Members chat and see usage; admins approve tool calls and manage providers, connections, tools, and agents.

  • Workspace safety

    Agents with the workspace skill aren't reachable from Slack, Discord, or Telegram unless you turn on their chat access.

Developers

Scriptable from end to end.

Everything the dashboard and terminal do goes through a documented HTTP and WebSocket API. Use the typed TypeScript client, call it from CI, or embed the runtime in your own service.

  • REST for agents, threads, providers, connectors, automations, and approvals
  • A WebSocket stream of messages, partial answers, and tool progress
  • The admin token or a signed-in user's session on every call

Step-by-step deploy guides

Built for agents

Hand it to your coding agent.

Paste this into Claude Code, Codex, or any agent with a shell. It installs soloagent, starts the dashboard, and gives you the URL and token, then stops before it touches your accounts.

Agents can read soloagent.dev/llms.txt, a plain-text map of the docs.

prompt · for any coding agent
Set up soloagent (https://soloagent.dev), a self-hosted control plane for AI agents, on this machine.

1. Check the Node.js version with `node --version`.
   - 22.19 or newer: run `curl -fsSL https://soloagent.dev/install.sh | sh`.
   - Older or missing: use Docker instead:
     `docker run -d --name soloagent -p 7420:7420 -v soloagent:/data ghcr.io/nearbycoder/soloagent.dev`
2. Without Docker, start the web dashboard with `soloagent serve` as a background process. It runs in the foreground and listens on http://localhost:7420.
3. Get the admin token with `soloagent token` (with Docker: `docker logs soloagent | grep token`). Tell me the dashboard URL and the token.
4. Stop there. Don't sign in to model providers or enter API keys; I'll do that on the dashboard's Providers page.

Reference: https://soloagent.dev/llms.txt and https://soloagent.dev/docs/

Questions

Good to know.

Anything else? The docs go deeper, and issues are open.

Is it free?

Yes. soloagent is MIT-licensed and self-hosted. You pay your model provider and your host, nothing else.

Can I really use my Claude or ChatGPT subscription?

Yes, through the same OAuth sign-in flows Pi uses. Check each provider's terms; Anthropic, for example, bills third-party usage as extra usage rather than against plan limits.

What happens if the server restarts mid-answer?

The run resumes from its last committed step. Completed tool calls are not repeated, and an interrupted model request is retried.

Do I need a public URL for Slack?

No. Slack uses Socket Mode, and Discord and Telegram connect outbound too. A domain is only needed for the dashboard, webhooks, and remote terminal access.

Where is my data stored?

In two SQLite databases in your data directory. Nothing leaves your server except requests to the model providers you configure.

What is Pi?

Earendil's open-source agent toolkit. soloagent uses pi-ai for models, pi-durable for durable execution, and pi-tui for the terminal UI.
